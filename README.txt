HAPPI BEANS WEBSITE
===================

A complete static, responsive website built with plain HTML, CSS and JavaScript.
No API key, backend, database, account, build step or paid website builder is required.

PREVIEW
-------
Open index.html in a browser.

PUBLISH FOR FREE ON NETLIFY
---------------------------
1. Extract the ZIP file.
2. Open https://app.netlify.com/drop in your browser.
3. Sign in or create a free Netlify account.
4. Upload the extracted folder (the folder containing index.html).
5. Netlify will publish the website and give you a public .netlify.app URL.

IMPORTANT
---------
- The menu and prices are stored locally in script.js.
- Business details are in index.html.
- Images supplied for this project are in assets/.
- To change menu items/prices, edit menuData in script.js.
- To change email/address/hours, edit the Visit section in index.html.
- No phone number, social media links, ordering system or payment system has been invented.
- Check all prices and business details with the owner before publishing.
